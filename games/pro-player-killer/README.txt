PRO PLAYER KILLER　完全版（ver.17／2026-11-20）
==================================================
プロゲーマーですら心が折れかける、究極の高難易度ダークファンタジー・アクション。

【同梱ファイル】
  index.html ...... ゲーム本体（このファイルだけで動きます）
  README.txt ...... このファイル（遊び方・システム・全データ）
  CHANGELOG.txt ... 更新履歴（ver.1〜ver.17）
  images/ ......... 画面写真・資料（一覧は末尾）


■ 1. 起動のしかた
--------------------------------------------------
index.html をブラウザで開くだけ（インストール・ネット接続は不要）。
対応：PC（Chrome / Edge / Safari / Firefox）、iPhone Safari、Android Chrome、ゲームパッド
・スマホは横画面で。縦にすると自動で一時停止します。
・スマホでは、ファイルを直接開くより Webサーバー（GitHub Pages / Netlify など）に置いてURLで開くのが確実です。
・BGMは最初のタップかキー入力から鳴ります。


■ 2. 操作
--------------------------------------------------
【PCキーボード】（設定→操作 でキー変更可）
  移動 ...... ← → / A D（2回押しでダッシュ）
  ジャンプ .. Space / W / ↑ / Z
  攻撃 ...... J / X（長押しで溜め斬り）
  回避 ...... K / C / Shift
  パリィ .... L / V（ボス報酬コスチューム着用時は専用カウンターになる）
  必殺技 .... U / B（ゲージ満タン時）
  スキル1 ... Q / I　　スキル2 ... E / O（ボス報酬コスチューム時）
  一時停止 .. Esc / P
  メニュー：↑↓選択、←→で値・グレード変更、Enter決定、Esc戻る

【スマートフォン】
  左：◀ ▶ 移動（2回タップでダッシュ）
  右：パリィ（青）・回避（緑）・攻撃（赤）・ジャンプ（金）、その上にスキル1・スキル2
  右上：一時停止／必殺（ゲージ満タン時に出現）
  ・スキルボタンは常に同じ位置。主人公（スキルなし）のときは暗いロック表示。
    着替えてもボタンの数・位置・大きさは変わらない。スキルとカウンターのボタンは衣装の色になる
  ・ボタン配置編集（一時停止メニュー／設定→操作）：ドラッグで移動、ボタンごとにサイズ50〜170%・透明度・表示切替。
    重なりや画面外は自動で補正。「初期配置に戻す」あり。回転・画面サイズが変わっても相対位置で保持

【ゲームパッド】
  左スティック／十字キー：移動　A：ジャンプ　X：攻撃　B：回避　Y：パリィ／カウンター
  LB：スキル1　RB：スキル2　トリガー：必殺技　START：一時停止

【技】
  ・攻撃3回→もう1回：回転斬り　・攻撃長押し→離す：溜め斬り　・ジャンプ直後に攻撃：斬り上げ
  ・空中で攻撃：空中斬撃（1ジャンプ2回まで）　・回避中／直後に攻撃：突進斬り
  ・攻撃の直前に回避：ジャスト回避（スロー、次の突進斬り強化）
  ・パリィ成功直後に攻撃：致命の一撃

【基本ルール】すべての敵・ボスで共通
  白い閃光 ＝ パリィ可能　／　赤い閃光 ＝ パリィ不可（回避の無敵か移動でかわす）
  地面の赤い印・円・破線 ＝ 攻撃の予兆。死んだときは死因とヒントが表示される


■ 3. タイトル・メニュー
--------------------------------------------------
  GAME START ... 難易度を選んで新しく始める（スロットのセーブは消えない／オートセーブは上書き）
  CONTINUE ..... 最新のセーブ（オートセーブ含む）から再開
  COSTUME ...... コスチューム変更
  RECORD ....... 難易度別の最高スコア
  SETTINGS ..... 音量（マスター／BGM／効果音）、画面の揺れ、閃光演出、タッチボタン表示、キー割り当て、ボタン配置
タイトルメニューは画面サイズに合わせて自動で拡大・縮小。

一時停止メニュー：ゲーム再開／操作設定／ボタン配置編集／コスチューム／セーブ／ロード／
  マップに戻る（ストーリー中）またはリタイア（ボスラッシュ中）／タイトル画面に戻る


■ 4. ワールドマップと進行
--------------------------------------------------
GAME START→難易度選択のあと、ワールドマップに出る。章を選んで「出発する」。
  ・クリア済みの章＝金色（何度でも再挑戦できる）、次に進める章＝赤く光る
  ・マップ右上：セーブ／衣装／タイトル
  ・マップ右側の「ボスの塔」＝ボスラッシュ（7章）

【章の構成】全10章・ボス10体
  第一章 腐敗の門 ......... 処刑人
  第二章 逆さ鐘楼 ......... 鐘の魔女
  第三章 灰燼の聖堂 ....... 灰燼の大司教
  第四章 凍てつく墓所 ..... 氷棺の騎士
  第五章 毒沼の森 ......... 腐毒の大蛇
  第六章 雷鳴の尖塔 ....... 雷帝
  第七章 血の闘技場 ....... 血塗れの剣闘士
  第八章 虚無の書庫 ....... 禁書の司書
  第九章 月下の庭園 ....... 月影の剣姫
  終章　 鏡の回廊 ......... 闇の鏡像（最終ボス。第一〜九章をすべてクリアすると挑戦可能）

【道中と中間地点】
  ・各章の道中は約8,000〜9,600。章ごとに背景の色合いと出てくる敵が違う
  ・各章に「中間地点」（旗とかがり火）が2か所。通るとHP全回復＋オートセーブ。死んでもそこから再開
  ・画面上の進行バー：◆＝中間地点、●＝ボス
  ・死ぬと道中の地形と敵の配置が少し変わり、あなたの癖に合わせて敵が変化する（学習・変異）

【セーブ】
  ・スロット1〜3（手動）＋オートセーブ（中間地点・章クリア・マップ到着で自動）
  ・マップ上でもセーブできる。CONTINUE は最新のセーブから


■ 5. 難易度
--------------------------------------------------
  NORMAL ...... 基準。初めての方はこちら
  HARD ........ 敵の耐久1.5倍・ボス1.2倍、攻撃が速く、重い攻撃+1。ボスはフェイント・遅延攻撃を最初から使う
  NIGHTMARE ... 敵の耐久1.8倍・ボス1.4倍、さらに速く、全攻撃+1。連続攻撃と追加パターンが増える。
                ボス戦のパリィ受付8F・回避無敵11F
  INFERNO ..... 最上位。敵の耐久2.1倍・ボス1.6倍、最速。ボス戦のパリィ受付7F・回避無敵10F
HARD以上ではボスに「ガード」が付き、通常攻撃のダメージが減る（HARD 72%／NIGHTMARE 55%／INFERNO 45%）。
スキル・カウンター・致命の一撃でガードを削ると「BREAK」：ボスが約2.5秒止まり、ダメージ1.5倍。
ボスは難易度ごとに見た目が変わる（HARDは強化、NIGHTMAREは禍々しい赤黒、INFERNOは黒と金＋炎の光輪）。


■ 6. ボス（10体）
--------------------------------------------------
どのボスもHPに応じて4段階で変化し、段階ごとに新しい技が解禁・速度が上がる。
ボスはプレイヤーの癖（攻撃連打・回避多用・パリィ多用・跳躍多用・距離取り・同じスキルの連発）を読んで対応してくる。
  処刑人 ........... 斧の連続コンボ、突進、大地崩し、断罪の鎖、最終段階は連続処刑
  鐘の魔女 ......... 鐘の雨、時間差の魔法陣、鐘の檻、音波の連鎖、終焉のレクイエム
  灰燼の大司教 ..... 香炉の連打、地を這う炎、火刑柱、火球、灰の雨、突進、浄火の円
  氷棺の騎士 ....... 剣の連撃、遠い刺突、地を走る氷の棘、氷柱の雨、氷結突進、凍結の陣、三条の氷槍
  腐毒の大蛇 ....... 噛みつき（連続）、尾の薙ぎ払い、毒液、毒弾、地中からの奇襲、酸の雨、蜘蛛の召喚
  雷帝 ............. 槍、薙ぎ払い、落雷、雷鎖、追尾雷球、背後への瞬間移動、天雷、雷撃降下
  血塗れの剣闘士 ... 高速連撃、盾打ち、剛撃、跳躍叩きつけ、旋風、突撃、投げ槍、雄叫び
  禁書の司書 ....... 頁の刃（扇状）、魔弾、虚無の印、瞬間移動、虚無の雨、霊火の召喚
  月影の剣姫 ....... 高速連撃、背後からの居合、三日月の斬撃、閃、花吹雪、満月、月下十字
  闇の鏡像 ......... 瞬間移動の連続斬り、鏡像の時間差突進、鏡片嵐、装備の模倣、深淵の鏡像（最終形態あり）

  名前          スキル1／スキル2              カウンター        必殺技
  主人公        なし                          パリィ            闇の鏡像
  処刑人        処刑の一撃／処刑人の威圧      処刑カウンター    処刑の連鎖
  鐘の魔女      魔鐘召喚／呪鐘共鳴            共鳴カウンター    禁断の大鐘
  闇の鏡像      影渡り／鏡像分身              鏡影カウンター    深淵の鏡
  灰燼の司教    劫火柱／聖灰の加護            浄火カウンター    天焦がす劫火
  氷棺の騎士    氷槍陣／凍結領域              氷結カウンター    永久凍土
  毒蛇の狩人    毒牙突進／毒霧                毒牙カウンター    大蛇顕現
  雷帝          落雷／雷纏い                  雷撃カウンター    万雷
  血の剣闘士    旋風斬／闘志                  剛撃カウンター    血闘乱舞
  禁書の司書    頁刃／浮遊魔書                封印カウンター    禁書解放
  月影の剣姫    月閃／朧月                    月影カウンター    月下乱れ桜

【グレード】倒した難易度でグレードが決まり、上の難易度で倒すとグレードアップ（下がることはない）
  NORMAL：基本性能　HARD：威力+20%・CT-15%・効果時間+15%
  NIGHTMARE：威力+40%・CT-30%・効果時間+30%　INFERNO：威力+60%・CT-40%・効果時間+45%
  見た目もグレードごとに変わる。解放済みのグレードはコスチューム画面で自由に切り替え可能

【コスチューム画面】
  左＝一覧、右＝詳細と大きなプレビュー。1回目のタップで詳細、「着用する」（または同じ行をもう一度タップ）で着替え。
  リストは指でなぞってスクロール（慣性あり、スクロール中に誤って押さない）。
  キーボード・パッド：↑↓で選択、←→でグレード変更、Enterで着用
  解放状況は端末に保存（セーブデータとは別）


■ 9. ボスの塔（ボスラッシュ）
--------------------------------------------------
マップ右の塔から挑戦。ストーリーとは別モード。
  ・ストーリーで一度倒したボスが章の順に連続で出てくる（最大10体）
  ・難易度は自由に選べる。次のボスへ進むとHPが半分回復、死亡で挑戦終了
  ・タイムは1/100秒まで計測（ボス戦中のみ。演出や移動の時間は含まない）
  ・難易度ごとにベスト記録（撃破数が多い方→同じならタイムが速い方が上）
  ・終了後は結果画面（ボスごとの通過タイム）→「もう一度」か「塔を出る」


■ 10. スコアと記録
--------------------------------------------------
撃破数・パリィ・カウンター・回避・BREAK・進んだ章で加点、死亡と被弾で減点、難易度で倍率
（NORMAL ×1／HARD ×1.6／NIGHTMARE ×2.4／INFERNO ×3.4）。終章クリアでランク（S〜D）とクリアボーナス。
RECORD画面に難易度ごとの最高スコアを保存。
