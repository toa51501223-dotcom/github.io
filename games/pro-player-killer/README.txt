PRO PLAYER KILLER  ver.17
=========================

■ 遊び方
index.html をブラウザで開くだけで遊べます（インターネット接続・インストール不要）。
対応：PCブラウザ（Chrome / Edge / Safari / Firefox）、iPhone Safari、Android Chrome

※ スマートフォンでは、ファイルを直接開くより、
  Webサーバー（GitHub Pages / Netlify など）に置いてURLで開くのが確実です。
※ スマートフォンは横画面でプレイしてください。
※ BGMは最初に画面をタップするか、キーを押してから鳴り始めます。

■ タイトル画面
GAME START ...... 難易度を選んで最初から始める（セーブがある場合は確認あり。セーブは消えません）
CONTINUE ........ 最新のセーブデータから再開（難易度もセーブ時のまま）
COSTUME ......... コスチューム変更
RECORD .......... 難易度別の戦績（ハイスコア）
SETTINGS ........ サウンド／操作（キー変更・ボタン配置）／その他
PCは ↑↓ で選択・Enter で決定・Esc で戻る。マウス操作も可。

■ 一時停止メニュー（右上の ❚❚ ／ Esc ／ P）
ゲーム再開・操作設定・ボタン配置編集・セーブ・ロード・タイトル画面に戻る
・一時停止中は敵・プレイヤー・演出・時間・当たり判定がすべて止まります。
・未セーブで戻ろうとすると「セーブして戻る／保存せず戻る」を選べます。

■ 難易度
NORMAL ...... 従来どおりの基準難易度
HARD ........ 敵の耐久1.5倍・ボス1.2倍、攻撃頻度/速度アップ、重い攻撃のダメージ+1、
              ボスはフェイント・遅延攻撃などを最初から使用、連続攻撃あり
NIGHTMARE ... 敵の耐久1.8倍・ボス1.4倍、さらに高速、すべての攻撃ダメージ+1、
              連続攻撃が増え、追加パターン（鏡像など）も最初から解禁
INFERNO ..... 最上位難易度（ver.17）。敵の耐久2.1倍・ボス1.6倍、最速（1.36倍〜最終段階1.9倍）、
              攻撃後の隙が最も短く連続攻撃55%。ボス戦のパリィ受付7フレーム・回避無敵10フレーム。
              通常攻撃はボスに45%しか通らず、カウンター2回でRESIST。グレードアップした力が必要
HARD以上ではボスに「ガード」が付き、通常攻撃のダメージが減ります（HARD 72%／NIGHTMARE 55%）。
スキル・カウンター・致命の一撃でガードゲージを溜めると「BREAK」：ボスが約2.5秒止まり、
その間はダメージ1.5倍。特殊能力とカウンターが攻略の鍵になります。

■ ボス（ver.8で大幅強化）
3体のボスはHPに応じて4段階のフェーズで戦い方が変わります（変わる瞬間に段階名が表示されます）。
  第1段階 … 基本の攻撃
  第2段階 … 新しい攻撃と連続攻撃が解禁、攻撃後の隙が短くなる
  第3段階 … 本気モード。大技・特殊行動が解禁
  最終段階 … 最も危険な攻撃を連ねて追い詰めてくる
・処刑人：突進／斧の連続コンボ（3〜4連）／大地崩し（中心から外へ、本気以降は外から返る）／
          最終段階は「連続処刑」（鎖→高速振り下ろし×2→薙ぎ→突進→大地崩し→断罪の鎖）
・鐘の魔女：鐘の雨（抜け道は1か所）／時間差魔法陣の列／鐘の檻（左右の壁＋足元の陣）／音波の連鎖／
          最終段階は「終焉のレクイエム」（鐘の雨→音波→魔法陣の列→追尾霊弾）
・闇の鏡像：瞬間移動の連続斬り／複数の鏡像の時間差突進／鏡片嵐（破片の雨と左右からの挟撃）／
          装備を真似る「模倣」／最終段階は「深淵の鏡像」（4体の鏡像→破片→柱→連続斬り）
ボスはプレイヤーの癖を読みます：
  攻撃連打→薙ぎ払いで割り込む・回避多用→溜め（遅延）攻撃・パリィ／カウンター多用→赤い（パリィ不可）攻撃とフェイント・
  跳躍多用→対空・距離を取る→突進や遠距離攻撃・同じスキルを繰り返す→「見切り」で避けるようになる
すべての攻撃には予兆（閃光・地面の印・破線・影）があり、見極めれば回避やカウンターで対応できます。

難易度ごとのボス
  NORMAL … 従来より強い。適当に攻撃しているだけでは勝てない
  HARD ……… 攻撃後の隙が短く、AIが賢い。連続攻撃とフェーズ変化が激しい
  NIGHTMARE … 隙が極めて短く、連携が最も激しい。ボス戦ではパリィ受付・回避の無敵時間が短くなり
               （パリィ10→8フレーム、回避無敵13→11フレーム）、ボスの重い攻撃はダメージがさらに+1。
               カウンターを3回続けると「RESIST」で怯まなくなり、BREAKするたびに次のBREAKが難しくなる
※ コスチュームの攻撃力・スキル・カウンターの性能と演出は変えていません。

■ コスチュームのグレードアップ（ver.10〜11）
ボスを倒した難易度に合わせて、そのボスのコスチュームが見た目も性能も強化されます。
  NORMALで撃破    → 通常仕様で解放（基本性能）
  HARDで撃破      → HARD仕様（威力+20%・クールダウン-15%・効果時間+15%）
  NIGHTMAREで撃破 → NIGHTMARE仕様（威力+40%・クールダウン-30%・効果時間+30%、魔女の魔鐘+1）
  INFERNOで撃破   → INFERNO仕様（威力+60%・クールダウン-40%・効果時間+45%、魔女の魔鐘+2、炎の光輪）
  ※威力＝スキル・必殺技・カウンターのダメージとガード削り。効果時間＝威圧・魔鐘・共鳴陣・分身
・まだ解放していないコスチュームをHARD/NIGHTMAREで倒した場合は、その仕様でいきなり解放されます。
・低い難易度で倒しても下がりません。解放済みの仕様は COSTUME 画面のボタンで自由に切り替えられます。
・選んだグレードの性能が適用されます（低いグレードを選べば性能も下がります）。
・解放状況はセーブデータとは別に端末へ保存されます。

■ スコアと戦績（RECORD）
クリア時（またはプレイ途中でタイトルへ戻った時）にスコアを計算し、
難易度ごとに「以前の最高スコアを超えた場合だけ」記録を更新します（同点・低い点では更新しません）。
記録内容：BEST SCORE／クリア状況／CLEAR TIME／ENEMIES DEFEATED／使用コスチューム／更新日時
保存先：ブラウザの localStorage（ppk_records_v1）。セーブスロットとは別領域で、閉じても残ります。

■ セーブ／ロード
・スロット3つ。日時・ステージ名・HP・撃破数・死亡数・プレイ時間を表示。
・上書き・ロード時は確認が出ます。空きスロットはメッセージ表示。
・ボス戦中などにセーブした場合は、安全な地点（ボス部屋の手前）から再開します。
・データはブラウザ（localStorage）に保存され、閉じても残ります。
  データが壊れていても起動は止まらず、該当スロットに「破損」と表示され削除できます。
※ 同じブラウザ・同じ場所（URL）で開いたときに引き継がれます。
  プライベートブラウズでは保存されない場合があります。

■ ボタン配置の編集（スマートフォン）
一時停止メニュー「ボタン配置編集」または 設定→操作→「配置を編集する」
・ボタンをドラッグで自由に移動（重なり・画面外は自動で補正）
・選んだボタンごとにサイズ（50〜170%）・透明度・表示/非表示を変更
・「保存」で端末に記録。「初期配置に戻す」「キャンセル」も可。
・位置は画面比率で保存されるので、画面サイズや向きが変わっても崩れません。

■ コスチューム（ボス報酬スキン）
タイトル画面「COSTUME」または一時停止メニュー「コスチューム」で着替えられます。
ボスを倒すと解放され、解放状況と着用中のスキンは端末に保存されます。
（セーブデータを消しても、ゲームをやり直しても解放は残ります）

ボス報酬コスチュームは、スキル2つ（クールダウン制）＋必殺技（ゲージ制）＋専用カウンターを持ちます。
パリィボタンはコスチュームに合わせて自動で「専用カウンター」に切り替わります（受付時間は従来と同じ）。
主人公（標準）に戻すと従来のパリィ（＋致命の一撃）に戻ります。パリィとカウンターが同時に発動することはありません。

・処刑人（第一章のボスを倒すと解放）　テーマ：重量・破壊
  スキル1「処刑の一撃」（7秒）：巨大斧で地面を砕く広範囲攻撃
  スキル2「処刑人の威圧」（20秒）：8秒間 攻撃+1・ガード破壊2倍、周囲の雑魚を吹き飛ばす
  必殺技「処刑の連鎖」：斧の2連撃→跳躍叩きつけ→前方へ地裂の衝撃波
  カウンター「処刑カウンター」：斧で受け止め、振り下ろしで地面を割る赤い衝撃波
  特性：溜め斬りのダメージ+1・間合い拡大
・鐘の魔女（第二章のボスを倒すと解放）　テーマ：魔法・広範囲・空間支配
  スキル1「魔鐘召喚」（8秒）：鐘3つが7秒間浮遊し、近くの敵へ自動で音波攻撃
  スキル2「呪鐘共鳴」（15秒）：5秒間の魔法陣。中の敵は半分の速さ・弾を消去・音波ダメージ
  必殺技「禁断の大鐘」：巨大な鐘を3度鳴らして画面全体に魔力波＋全体を約5秒間スロー
  カウンター「共鳴カウンター」：魔法陣と鐘で受け、音波の衝撃波。攻撃してきたボスの行動を止める
・闇の鏡像（最終ボスを倒すと解放）　テーマ：速度・分身・連続攻撃
  スキル1「影渡り」（5秒）：敵の背後へ瞬間移動して2連斬り
  スキル2「鏡像分身」（16秒）：9秒間 分身2体が付き従い、攻撃が当たるたびに追撃
  必殺技「深淵の鏡」：4体の分身で包囲して12連斬り、鏡を砕いて破片で貫く
  カウンター「鏡影カウンター」：姿を消して敵の背後へ移動し、深紅の3連斬り
  特性：見切り（ジャスト回避）時に分身が近くの敵を斬る
・主人公（標準）：必殺技「闇の鏡像」とパリィは従来どおり。

■ 技
・攻撃3回 → もう1回：4段目の回転斬り
・攻撃長押し → 離す：溜め斬り（強攻撃）
・ジャンプ直後に攻撃：斬り上げ
・空中で攻撃：空中斬撃（1回のジャンプで2回まで）
・回避中／回避直後に攻撃：突進斬り
・攻撃の直前に回避：ジャスト回避（スロー＋次の突進斬りが強化）
・攻撃に合わせてパリィ：パリィ成功 → 次の一撃が「致命の一撃」
  受付の最初の瞬間ならジャストパリィ
・必殺技「闇の鏡像」：攻撃を当てる・パリィ・ジャスト回避でゲージが溜まる

■ 攻撃の見分け方
白い閃光・白い印 ＝ パリィ可能
赤い閃光・赤い印 ＝ パリィ不可（回避・ジャンプ・移動でかわす）
死ぬたびに世界はあなたの癖を学習して変化します。
