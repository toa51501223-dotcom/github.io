PRO PLAYER KILLER
==================

■ 遊び方
index.html をブラウザで開くだけで遊べます（インターネット接続・インストール不要）。
対応：PCブラウザ（Chrome / Edge / Safari / Firefox）、iPhone Safari、Android Chrome

※ スマートフォンでは、ファイルを直接開くより、
  Webサーバー（GitHub Pages / Netlify など）に置いてURLで開くのが確実です。
※ スマートフォンは横画面でプレイしてください。
※ BGMは最初に画面をタップするか、キーを押してから鳴り始めます。

■ 操作（PCキーボード）
移動 ............ ← → / A D（2回押しでダッシュ）
ジャンプ ........ Space / W / ↑ / Z
攻撃 ............ J / X（長押しで溜め斬り）
回避 ............ K / C / Shift
パリィ .......... L / V
必殺技 .......... U / B（ゲージ満タン時）
一時停止 ........ Esc / P

■ 操作（スマートフォン）
画面左：◀ ▶ 移動（2回タップでダッシュ）
画面右：パリィ・回避・攻撃・ジャンプ
右上：一時停止／必殺（ゲージ満タン時に表示）

■ 操作（ゲームパッド）
左スティック／十字キー：移動　A：ジャンプ　X：攻撃
B / RB：回避　Y / LB：パリィ　トリガー：必殺技　START：一時停止

■ 技
・攻撃3回 → もう1回：4段目の回転斬り
・攻撃長押し → 離す：溜め斬り（強攻撃）
・ジャンプ直後に攻撃：斬り上げ
・空中で攻撃：空中斬撃（1回のジャンプで2回まで）
・回避中／回避直後に攻撃：突進斬り
・攻撃の直前に回避：ジャスト回避（スロー＋次の突進斬りが強化）
・攻撃に合わせてパリィ：パリィ成功 → 次の一撃が「致命の一撃」
  受付の最初の瞬間ならジャストパリィ
・必殺技「闇の鏡像」：攻撃を当てる・パリィ・ジャスト回避でゲージが溜まる

■ 攻撃の見分け方
白い閃光・白い印 ＝ パリィ可能
赤い閃光・赤い印 ＝ パリィ不可（回避・ジャンプ・移動でかわす）
死ぬたびに世界はあなたの癖を学習して変化します。
