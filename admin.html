管理ページ

ゲームの追加・削除・更新・PV、サイト本体の更新ができます。操作にはあなたの GitHub のトークンが必要です。

ログイン

GitHub のトークンと、サイトを置いているリポジトリを入力してください。トークンはこの端末の中にだけ保存され、GitHub 以外には送信されません。

トークンの作り方
  1. GitHub にログインして github.com/settings/personal-access-tokens/new を開く
  2. Token name に「quveris-admin」、Expiration（有効期限）は長めを選ぶ
  3. Repository access で「Only select repositories」→ サイトのリポジトリを選ぶ
  4. Permissions の Repository permissions で「Contents」を Read and write、「Pages」を Read-only にする
  5. 「Generate token」を押して、表示された文字列をコピーしてここに貼り付け

トークンは他の人に教えないでください。漏れたら同じ画面で削除（Revoke）すれば無効になります。
